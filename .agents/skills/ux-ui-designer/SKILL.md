# UX/UI Designer — Experiência Visual e Apresentação de Dados

Esta skill orienta a apresentação visual, legibilidade e usabilidade de todos os produtos gerados pelo projeto (planilhas Excel, relatórios de dados e dashboards).

## 1. Princípios de Design para Dados Acadêmicos

1. **Hierarquia Visual na Planilha de Catalogação:**
   * **Cabeçalhos:** Fonte em negrito, fundo sutil (azul ou cinza grafite), texto centralizado e filtros automáticos ativados.
   * **Formatação Condicional:**
     * `Status = 'Catalogado'`: Fundo verde suave (`#D4EDDA`).
     * `Status = 'Pendente'`: Fundo amarelo suave (`#FFF3CD`).
     * `Status = 'Duvida'`: Fundo vermelho suave (`#F8D7DA`).
   * **Largura das Colunas:** Ajustadas automaticamente ao conteúdo, com quebra de texto (*wrap text*) para o corpo das mensagens e notas netnográficas.
   * **Fixação de Painéis (*Freeze Panes*):** A primeira linha de cabeçalho e a coluna de ID/Data devem permanecer fixas durante a rolagem horizontal/vertical.

2. **Visualização de Estatística Descritiva (Pronta para a Monografia):**
   * Gráficos limpos sem poluição visual (*chartjunk*).
   * Paletas de cores acessíveis com alto contraste.
   * Rótulos explícitos de eixos e legendas que facilitem a leitura direta pela banca examinadora.
